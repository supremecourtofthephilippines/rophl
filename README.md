# Republic of Philippines Roleplay — Rules of Court

A fictional, organized Rules of Court reference website inspired by the visual structure of the Philippine Supreme Court's Rules of Court page.

## Important

This project is for roleplay purposes only. It is not the official Supreme Court website, is not affiliated with the Judiciary of the Philippines, and must not be used as legal advice or authority in real proceedings.

## Run locally

Open `index.html` directly in a browser, or serve the directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page structure and rule sections
- `styles.css` — responsive presentation
- `script.js` — search and mobile navigation

## GitHub Pages

Repository **Settings** → **Pages** → **Deploy from a branch** → `main` → `/ (root)`.
