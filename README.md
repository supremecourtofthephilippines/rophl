# Republic of the Philippines Roleplay — Rules of Court

A responsive roleplay reference index inspired by the layout of the Supreme Court Rules of Court listing.

## Roleplay disclaimer

This is an unofficial fictional roleplay project. It is not affiliated with or endorsed by the Supreme Court of the Philippines, does not provide legal advice, and must not be used as authority in real proceedings. The linked roleplay PDFs are original, abridged adaptations, not official court texts.

## PDF documents

Selecting a title or case number opens a generated PDF directly in the browser's built-in PDF viewer. PDFs are generated locally in the browser from the roleplay document text in `documents.js`; use the PDF viewer's download control to save a copy. No third-party PDF library is required.

## Run locally

Serve the repository directory (the `file://` protocol can restrict browser behavior):

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
